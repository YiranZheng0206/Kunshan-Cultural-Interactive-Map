# Image-to-record audit

Audit date: 20–21 October 2026

## Method

- Reviewed a labeled contact sheet of all 82 record images against the English and Chinese record names.
- Confirmed that every referenced local image file opens successfully.
- Checked exact-file hashes: no exact duplicate files were found.
- Checked dimensions: no referenced file is below 250 × 160 pixels.
- Treated a visually plausible image as **not verified** until its source page explicitly identifies the same place, object, food, tradition, or story.

## Release boundary

An image being stored locally does not establish permission to redistribute it. Before the final public release, the team should verify the source page, subject identity, creator/publisher, license or permission, access date, and required attribution for every image. Until then, the interface should treat non-verified images as illustrative rather than evidentiary.

The interface now displays both a subject-match label and an image-rights label beside every record image. A green subject label does not override the separate rights warning.
